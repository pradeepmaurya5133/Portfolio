Overview

A personal portfolio showcasing my technical expertise, selected projects, professional experience, and freelance development services.

Every page is generated by a Python build script from a single data source, so the same facts drive the HTML, the sitemap, the structured data and the machine-readable versions of each page. Editing one entry updates the site everywhere it appears.

The front end is vanilla JavaScript with GSAP and Lenis — no framework — and the contact form is backed by a serverless function on Vercel with validation, spam filtering and a graceful fallback when mail delivery is unavailable.

One source of truth

Content lives in structured data rather than in markup, so a change to a project or a job title propagates to every page, feed and metadata file in a single build.

Built to be read by machines too

Alongside the HTML, each page is published as markdown, with an OpenAPI description for the contact API and discovery metadata for automated clients.
