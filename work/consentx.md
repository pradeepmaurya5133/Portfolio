# ConsentX — Pradeep Maurya

A consent management platform where privacy choices have to be captured, stored and proven.

Canonical: https://www.pradeepmaury.in/work/consentx.html

---

Contributed to full-stack development and ongoing enhancement of ConsentX.io — a consent management platform — covering responsive UI, user-facing functionality, testing and usability improvements.

Working on a live product, the brief was rarely "build this screen." It was closer to "this flow confuses people and the numbers show it." Most of my work sat in that gap: taking an existing interface, finding where it broke down on real viewports and real data, and rebuilding it so the consent journey reads clearly from first load to confirmation.

Beyond the frontend, I picked up backend tasks and application functionality, debugged issues reported from production, and tested each change manually and through the API before it shipped.

### Responsive first

Consent interfaces get opened on whatever device is nearest. Every layout was rebuilt to hold up from a narrow phone through to a wide desktop without a separate mobile path to maintain.

### Tested before shipped

Each change went through manual web testing plus API checks in Postman, so regressions were caught before review rather than after release.
