Profile

I'm a Computer Science graduate based in Dehradun, working as a Full Stack Developer at iLeads Auxiliary Services on two live platforms — ConsentX.io and RegulatoryBridge.com.

My work spans the full stack: responsive interfaces in React and Next.js, backends in Node.js and Django, and the manual and API testing that keeps both honest. Before this I spent a year in QA and data support, which is where the testing habit came from.

Computer Science graduate with hands-on experience in web development, software testing and data analysis. Working knowledge of HTML, CSS, JavaScript, React, Next.js, Node.js, Python, TypeScript, Tailwind CSS, Git/GitHub, REST APIs and AI API integration. Focused on building responsive interfaces, improving application usability and debugging web applications.

“I'd rather ship a smaller feature that holds up than a bigger one that needs a hotfix on Monday. Build it, test it properly, then put it in front of people.”
